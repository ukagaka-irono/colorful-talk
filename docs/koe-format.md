# 記号列（koe string）の仕様

colorful-talk に渡すテキストは、読みをカナで書き、アクセントや区切りを記号で示した「記号列」です。
文字コードは UTF-8 です。漢字・英数字は読めないので、アプリ側で読みに変換してから渡してください。

## 文字

| 書き方 | 意味 |
|---|---|
| ひらがな・カタカナ | 発音する音。どちらで書いても同じ。拗音（きゃ）・外来音（ふぁ, てぃ, うぃ, ゔぁ など）も可 |
| `ー` `～` `〜` | 長音。直前の母音を 1 モーラ延ばす |
| `っ` | 促音。後ろが破裂音なら無音、摩擦音（さ行・しゃ行など）ならその音を延ばす |
| `ん` | 撥音。後ろの子音に合わせて m / n / ŋ / 鼻母音に変わる |
| 空白・改行 | 無視 |

「は」「へ」「を」は書いたとおりに読みます。助詞は発音どおり **わ・え・お** と書いてください（`こんにちわ`）。

## アクセント・区切り

| 記号 | 意味 |
|---|---|
| `'`（`’` `＇` も可） | アクセント核。この直前のモーラの後で声が下がる |
| `/`（`／`） | アクセント句の区切り（間を空けない） |
| `、` `,` `，` | 短い間（約 0.2 秒）。アクセント句の区切りも兼ねる |
| `。` `.` `．` `！` `!` | 文末。長い間（約 0.4 秒）、声を下げて終わる |
| `？` `?` | 疑問の文末。語尾を上げる |
| `_`（`＿`） | 直後のモーラの母音を無声化する |

アクセントは東京方言の規則で付きます。

- `'` のない句は **平板型**（1 モーラ目が低く、2 モーラ目から高いまま）
- `は'し`（箸）: 頭高型。1 モーラ目だけ高い
- `はし'`（橋）: 尾高型。最後まで高く、続く句で下がる
- `こころ'ざし` のように句の途中に置けば中高型

アクセント句は「文節」程度の単位で区切ると自然になります。

```
きょ'うわ/い'い/てんきです。
わたしわ、にほんごを/はなしま'す。
ほんとうに/そ'うですか？
```

## 無声化

`き` `し` `す` `ち` `つ` `ひ` `ふ` `ぴ` `ぷ` などの i / u は、後ろに無声子音が続くと自動で無声化します
（例: `きた` の「き」、`です。` の「す」）。アクセント核のモーラと疑問文末は無声化しません。
自動で付かない所に付けたいときは `_` を前に置きます（`_あ` など）。

## エラー

使えない文字や記号の置き方が不正な場合は合成せずにエラーを返し、`CTalk_ErrorPos()` で
何文字目（0 始まり、UTF-8 のバイトではなく文字数）が原因かを取得できます。

| エラー | 例 |
|---|---|
| `CT_ERR_CHAR` | `あ漢` – 漢字や英字 |
| `CT_ERR_ACCENT` | `'あ` – 句頭の `'`、1 つの句に `'` が 2 つ |
| `CT_ERR_LONG` | `ーあ` – 句頭の `ー`、`っー` |
| `CT_ERR_DEVOICE` | `あ_` – `_` の後にカナがない、`_ん` |
| `CT_ERR_EMPTY` | `、。` – 発音する文字がない |
